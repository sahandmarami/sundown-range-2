# میدان غروب ۲ — نسخهٔ ۴ طلایی (Sundown Range II · V4 GOLD)

بازی تیراندازی تاکتیکی سه‌بعدی فارسی — تک‌فایل HTML با موتور Three.js، لیدربورد آنلاین، چالش روزانه و نسخهٔ اندروید (APK).

> 🎮 **همین الان بازی کن:** [نسخهٔ وب (GitHub Pages)](https://sahandmarami.github.io/sundown-range-2/game-src/) · 📱 **دانلود APK:** از بخش [Releases](https://github.com/sahandmarami/sundown-range-2/releases/latest) یا پوشهٔ [`download/`](download/)

---

## ✨ چه چیزهایی در نسخهٔ ۴ اضافه شد؟

### 🎨 جلوه‌های بصری
- **هدشات طلایی**: ذرات نور طلایی + مکث کوتاه زمان (slow-motion) + صدای زنگ روشن هنگام هدشات
- **فلش طلایی رکورد**: با ثبت رکورد جدید، نور طلایی تمام صفحه + فانفار پیروزی
- **افکت پالس** روی نشان «★ رکورد جدید ★» و هایلایت طلایی ردیف خودت در جدول رکوردها
- عدد امتیاز هدشات از صورتی به **طلایی** تغییر کرد

### 🔊 صدا و موسیقی
- ریزر صوتی هنگام ورود به **حالت آتش** (Fever) و ضرب‌آهنگ تندتر موسیقی در این حالت
- فانفار رکورد جدید، صدای باز شدن جعبهٔ جایزه و صدای کامل شدن چالش روزانه

### 📅 چالش روزانه
- هر روز یک مأموریت متفاوت بر اساس تاریخ: هدشات بزن / به امتیاز برس / زنجیره بساز / هدف حذف کن
- نوار پیشرفت زنده در منو + جایزهٔ ۱۲۰ تا ۱۵۰ سکه‌ای که یک بار در روز دریافت می‌شود

### 🎁 جایزه و پیشرفت
- **جعبهٔ جایزهٔ پایان راند**: سکهٔ اضافه بر اساس امتیاز (حداقل ۵ سکه) با انیمیشن باز شدن
- **پیام تشویقی هوشمند** بر اساس عملکرد (نزدیک به رکورد، دقت بالا، زنجیرهٔ طولانی و…)
- **مقایسه با رکورد قبلی**: «بهبود ۱۲٪ نسبت به رکورد قبلی»

### 🌐 لیدربورد v4 — سرویس ابری امن
- مهاجرت به **bin نسخهٔ ۴** با اسکیمای نسخه‌دار (`{v:2, scores, ts}`) — رکوردهای قبلی انتقال یافت
- **پشتیبان خودکار**: اگر bin اصلی در دسترس نباشد، از bin قدیمی (فقط‌خواندنی) خوانده می‌شود
- **اعتبارسنجی ورودی**: پاک‌سازی نام (طول، کاراکترهای خطرناک، فیلتر اسامی نامناسب) و سقف امتیاز
- **ضداسپم**: حداکثر یک ارسال در هر ۲۵ ثانیه + صف ارسال
- **رتبهٔ جهانی تو**: در منوی رکوردها و صفحهٔ پایان راند نمایش داده می‌شود
- تلاش مجدد هوشمند با backoff و ذخیرهٔ آفلاین در localStorage

### 📱 نسخهٔ اندروید (APK)
- ساخت با **Capacitor 8** · نسخهٔ `4.0` · پشتیبانی از اندروید ۷ به بالا (API 24+)
- آیکون تطبیقی اختصاصی (خورشید غروب + نشانه‌گیری) در همهٔ تراکم‌ها
- **کاملاً آفلاین**: Three.js و همهٔ کتابخانه‌ها داخل فایل بازی تعبیه شده‌اند
- امضاشده با کلید release — برای به‌روزرسانی‌های بعدی همان کلید لازم است

## 🚀 اجرا

**وب:** همین فایل `game-src/index.html` را در مرورگر باز کنید — بدون نیاز به اینترنت.

**اندروید:**
```bash
cd apk-project
npm install
npx cap sync android
cd android && ./gradlew assembleRelease
```

## 🏆 لیدربورد آنلاین — چطور کار می‌کند؟

| بخش | توضیح |
|---|---|
| ذخیره‌سازی | jsonbin.io — bin نسخهٔ ۴ (`6ab1a019ac6210605ae72028`) |
| انتقال داده | bin قدیمی به‌عنوان منبع پشتیبان خوانده می‌شود |
| ادغام | بالاترین امتیاز هر بازیکن نگه داشته می‌شود (تا ۱۰ نفر برتر) |
| محافظت | پاک‌سازی نام، سقف امتیاز، محدودیت نرخ ارسال |

> ⚠️ **نکتهٔ امنیتی:** کلید jsonbin در فایل بازی تعبیه شده (برای ذخیرهٔ امتیاز لازم است). برای ضدتقلب کامل، در آینده یک پراکسی سراسری (مثلاً Cloudflare Worker) بین بازی و jsonbin قرار دهید.
